# 2. Testing Fundamentals

This is the foundation you should master before automation.

## 2.1 What is Software Testing?

Understand:

- Verification
- Validation
- Quality Assurance
- Quality Control
- Testing vs Debugging
- Error
- Defect
- Failure
- Root cause

## 2.2 Testing Principles

Learn:

- Testing shows presence of defects
- Exhaustive testing is impossible
- Early testing
- Defect clustering
- Pesticide paradox
- Testing is context dependent
- Absence-of-errors fallacy

## 2.3 Testing Types

Understand:

### Functional

- Unit
- Integration
- System
- End-to-End
- Acceptance

### Non-functional

- Performance
- Security
- Usability
- Accessibility
- Compatibility
- Reliability
- Scalability
- Maintainability
- Observability

### Based on execution

- Static testing
- Dynamic testing

### Based on change

- Regression testing
- Retesting
- Smoke testing
- Sanity testing

### Based on access

- Black-box
- White-box
- Gray-box
